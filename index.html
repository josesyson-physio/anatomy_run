    Anatomy Run is made by MotionPlus Physio Pvt. Ltd., Hyderabad, Telangana, India ("we"). We decide how the personal data described here is used.

    How to play · 20 seconds
    1. Run and jump. Use Back, Forward and Jump (or arrow keys and Space). Stomp enemies from above.
    2. Touch a clue gem. Answer the question to decode it. Wrong answers still teach you; you can also skip.
    3. Reach the clinic door. Read the case file and make the diagnosis. Then see your recap and takeaways.
