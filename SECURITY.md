# Security policy

## Reporting a vulnerability

Email **admin@motionplusphysio.in** with the subject `Anatomy Run security`.
Please include steps to reproduce and the browser or device you used.
Do not open a public issue for security problems.

We aim to reply within 3 working days and to fix confirmed issues within 14 days.
Please give us a reasonable chance to fix a problem before you disclose it publicly.

## Scope

- The game page (`index.html`) and anything it loads
- The donation flow (UPI QR codes and UPI ID shown in the game)

Out of scope: denial-of-service, social-engineering of staff, issues in GitHub,
Google Fonts or a payment app themselves, and reports that only affect a
player's own browser storage.

## Supported versions

Only the version currently deployed from `main` is supported.

## Payment safety notice for players

Anatomy Run never asks for card numbers, UPI PINs, OTPs or passwords. The only
official UPI ID is **jose496@ybl**. If you see anything else, do not pay and tell us.
